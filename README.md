# 🛡️ Smart Safety Network

A real-time emergency response platform designed to connect women in distress with trusted contacts, nearby volunteers, and emergency services. The system uses live GPS location tracking and intelligent alert mechanisms to support faster emergency response and improve personal safety.

## 🚨 Features

* 📍 **Live GPS Location** — Share and track the user's current location.
* 🆘 **Emergency Alerts** — Quickly trigger an emergency response.
* 👥 **Trusted Contacts** — Connect with predefined emergency contacts.
* 🤝 **Nearby Volunteers** — Enable assistance from nearby registered volunteers.
* 🚓 **Emergency Services** — Support communication with emergency responders.
* 🔔 **Intelligent Alerts** — Provide rapid notifications during emergencies.
* 🗺️ **Location Visualization** — Display emergency locations for faster assistance.
* 📱 **Responsive Interface** — Designed for use across desktop and mobile devices.

## 🎯 Objective

The objective of Smart Safety Network is to create a connected emergency-response ecosystem that reduces response time during critical situations.

The platform brings together:

**Person in Distress → Trusted Contacts → Nearby Volunteers → Emergency Services**

This approach aims to make emergency assistance faster, more coordinated, and location-aware.

## ▶️ How to Run

### Method 1 — VS Code Live Server

1. Clone the repository:

```bash
git clone https://github.com/ThanushaMuthuM/smart-safety-network.git
```

2. Open the project in VS Code:

```bash
cd smart-safety-network
code .
```

3. Install the **Live Server** extension in VS Code.

4. Right-click `index.html`.

5. Select **Open with Live Server**.

The application will open in your browser.

### Method 2 — Python Local Server

If Python is installed:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
